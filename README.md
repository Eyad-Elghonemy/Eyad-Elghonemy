## 📌 Featured Projects

### 🚗 OCTAL — Vehicle Price Prediction & Market Insights Platform
An end-to-end car price prediction system: predicts market price from manually entered specs **or from a VIN alone** (auto-decoded via the NHTSA API), with an embedded market-insights dashboard and an admin logs page.

* Designed and built the **ML model, FastAPI backend, and server hosting**
* Two-layer validation, Arabic-localized error messages with correct RTL rendering, and persistent operation logging via Supabase
* **Technologies:** `Python` `FastAPI` `scikit-learn` `Pandas` `NHTSA API` `Supabase` `Pydantic`

---

### 🚙 Car Damage Detection API (NTI Graduation Project)
A computer-vision API that detects and reports car damage from images, combining a fine-tuned **YOLOv8-seg** segmentation model with **Gemini** for damage explanation/reporting.

**Technologies:** `Python` `FastAPI` `YOLOv8-seg` `Gemini API` `Docker`

---

### 🧵 LOOM — Fashion MNIST Classification
A full-stack deep learning service classifying clothing images into 10 categories in real time, with a secured FastAPI backend, Supabase-backed request logging, duplicate-request detection, and a Streamlit "control room" for live usage analytics.

**Technologies:** `Python` `FastAPI` `TensorFlow/Keras` `Streamlit` `Supabase` `Pydantic`

---

### 🚢 RMS · 1912 — Titanic Survival Classification
A production-ready REST API predicting passenger survival using a trained Keras neural network, with engineered features (`family_size`, `is_alone`) and a clean, fully separated architecture.

**Technologies:** `Python` `FastAPI` `TensorFlow/Keras` `joblib`

---

### 💬 VibeAR — Arabic Sentiment Analysis
A REST API classifying Arabic text as Positive/Negative, shipped with a pre-trained default model (TF-IDF + Logistic Regression on ~58K tweets) — and the ability to train and hot-swap in a custom model live, with zero downtime.

**Technologies:** `Python` `FastAPI` `scikit-learn` `TF-IDF`

---

### 🛺 TokTok Detector — Auto-Rickshaw Detection
A YOLO-powered object detection API that spots toktoks in images and returns either a live count or an annotated bounding-box image, with an adjustable confidence threshold and a Streamlit control room.

**Technologies:** `Python` `FastAPI` `Ultralytics YOLO` `OpenCV` `Streamlit`
